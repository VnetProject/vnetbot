# 🤖 VNET Bot

ربات تلگرامی فروش خودکار نمایندگی (ادمین) روی پنل‌های **PasarGuard**، با کیف پول داخلی (کارت‌به‌کارت / TON)، کسر خودکار هزینه بر اساس مصرف، دریافت کانفیگ تست، و پنل مدیریت کامل داخل تلگرام.

## ✨ امکانات
- فروش نمایندگی با پلن‌های نامحدود (قیمت هر گیگ، قیمت هر ساعت، محدودیت یوزر، پنل، رول ادمین، حداقل موجودی)
- اتصال به یک یا چند پنل PasarGuard
- کیف پول داخلی با شارژ کارت‌به‌کارت یا TON (تبدیل خودکار تومان به TON)
- کسر خودکار ساعتی هزینه بر اساس مصرف واقعی؛ اتمام موجودی = غیرفعال‌شدن خودکار نمایندگی (بدون حذف)
- دریافت کانفیگ تست رایگان
- پیام همگانی، کانال جوین اجباری، کانال گزارشات
- سفارشی‌سازی کامل متن‌ها، رنگ دکمه‌ها و ایموجی پرمیوم از داخل تلگرام
- دستورات سریع: `/new` `/wallet` `/myplans` `/test` `/faq` `/rules` `/support`

---

## 📦 پیش‌نیاز
یک VPS با **Ubuntu 22.04 یا 24.04** و دسترسی root.

## 🚀 نصب (یک خط دستور)

```bash
bash <(curl -Ls https://raw.githubusercontent.com/VnetProject/vnetbot/main/install.sh) install
```

> به‌جای `USERNAME/REPO` آدرس ریپوی همین پروژه را بگذارید.
> ⚠️ همیشه فقط **یک دستور** به‌صورت جدا اجرا کنید (`install` یا `logs` یا ...) - چند دستور را با هم در یک خط ننویسید.

اسکریپت به‌صورت خودکار:
1. پیش‌نیازها (Python, MySQL, Git و ...) را نصب می‌کند
2. دیتابیس MySQL می‌سازد
3. کتابخانه‌های پایتون را نصب می‌کند
4. **توکن ربات** و **آیدی عددی ادمین** را از شما می‌پرسد
5. ربات را به‌صورت سرویس دائمی (systemd) اجرا می‌کند
6. یک دستور کوتاه به نام `vnetbot` می‌سازد تا از این به بعد نیازی به تایپ دوباره‌ی لینک نصب نباشد

در پایان نصب، خودِ اسکریپت وضعیت واقعی سرویس را چک می‌کند و اگر بالا نیامده باشد، همان لحظه دلیل خطا را (از روی لاگ) نشان می‌دهد.

### دستورات مدیریت (از هر جای سرور، بدون نیاز به curl دوباره)
```bash
vnetbot status       # وضعیت واقعی سرویس
vnetbot logs         # مشاهده لاگ‌های زنده (خروج با Ctrl+C)
vnetbot restart      # ری‌استارت ربات
vnetbot reconfigure  # اصلاح توکن/آیدی ادمین اشتباه، بدون نصب مجدد همه‌چیز
vnetbot update       # دریافت آخرین نسخه از گیت‌هاب + ری‌استارت
vnetbot uninstall    # حذف کامل ربات (دیتابیس حذف نمی‌شود)
```

> نکته: دستور `vnetbot` فقط بعد از یک بار اجرای موفق `install` ساخته می‌شود. اگر هنوز نصب نکرده‌اید یا نصب نیمه‌کاره مانده، همچنان از همان دستور کامل `bash <(curl ...) install` استفاده کنید.

## ⚙️ راه‌اندازی اولیه (بعد از نصب)

در تلگرام به ربات خودتان بروید و به ترتیب زیر پیش بروید:

1. دستور `/admin` را بفرستید تا پنل مدیریت باز شود.
2. **🖥 پنل‌ها** → افزودن پنل → نام، آدرس، یوزرنیم و پسورد ادمین sudo پنل PasarGuard خود را وارد کنید. ربات بلافاصله اتصال را تست کرده و نتیجه را نشان می‌دهد.
3. **📦 پلن‌ها** → افزودن پلن → قیمت هر گیگ، قیمت هر ساعت، محدودیت یوزر، پنل مربوطه و رول ادمین (ربات لیست رول‌های واقعی پنل شما را نشان می‌دهد) را مشخص کنید.
4. **⚙️ تنظیمات** → شماره کارت، ولت TON، نرخ دلار به تومان، حداقل/حداکثر شارژ و حجم/مدت تست را وارد کنید.
5. (اختیاری) **📣 کانال‌ها** → کانال جوین اجباری و کانال گزارشات را اضافه کنید (ربات باید در آن‌ها ادمین باشد).
6. (اختیاری) **📝 متن‌های ربات** و **🎨 دکمه‌ها** → متن خوش‌آمدگویی/قوانین/سوالات متداول و رنگ/ایموجی دکمه‌ها را سفارشی کنید.

ربات آماده استفاده است ✅

## 🎨 نکته: رنگ دکمه و ایموجی پرمیوم
- رنگ هر دکمه از «🎨 دکمه‌ها» در پنل مدیریت قابل تغییر است (آبی/سبز/قرمز/پیش‌فرض).
- برای ایموجی پرمیوم، کد وارد نمی‌کنید؛ کافیست خودِ ایموجی پرمیوم را در چت با ربات بفرستید (نیاز به Telegram Premium روی اکانتی دارد که ایموجی را می‌فرستد).
- در متن‌های ربات (خوش‌آمدگویی، قوانین و ...) هم می‌توانید هر تعداد ایموجی پرمیوم که بخواهید را همان‌جا داخل متن قرار دهید.

## ❓ ربات بالا نمی‌آید یا غیرفعال است؟

1. اول همیشه لاگ واقعی را ببینید (دلیل خطا دقیقاً همین‌جا مشخص می‌شود):
   ```bash
   vnetbot logs
   ```
   یا اگر دستور `vnetbot` هنوز ساخته نشده:
   ```bash
   journalctl -u vnetbot -n 50 --no-pager
   ```
2. رایج‌ترین دلیل، اشتباه بودن **توکن ربات** یا **آیدی عددی ادمین** موقع نصب است. برای اصلاح، نیازی به نصب کامل مجدد نیست:
   ```bash
   vnetbot reconfigure
   ```
3. اگر خطا مربوط به دیتابیس بود (مثلاً `Access denied` یا `Can't connect`)، مطمئن شوید سرویس MySQL بالاست:
   ```bash
   systemctl status mysql
   ```
